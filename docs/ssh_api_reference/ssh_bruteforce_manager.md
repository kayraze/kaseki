# SSH Brute Force Manager

## Overview

`sshbruteforcemanager.py` orchestrates SSH brute-force attacks by managing password production, result consumption, and execution of brute-forcing processes. It leverages multiprocessing to enhance performance and efficiency.

## Classes

The main class provided in this module is:

# SSHBruteForceManager

This class manages the overall brute-force attack process, coordinating password production, consumption of results, and the execution of SSH brute-forcers.

## Constructor

```python

    """
    Initializes the brute force manager with SSH target details and password list path.

        passlist_filename (str): Path to the password list file.
    """
```

## Attributes

**target (SSHTarget)**: Contains information about the SSH server, including hostname, port, and username.
**passlist_filename (str)**: Path to the file containing the list of passwords.
**passwords_queue (multiprocessing.Queue)**: Queue for passwords generated by the `PasswordProducer`.
**results_queue (multiprocessing.Queue)**: Queue for results collected from the `SSHBruteForcers`.
**running_bruteforce_proc (List[multiprocessing.Process])**: Tracks the running brute-force processes.
**password_failed_n (int)**: Counter for failed password attempts.
