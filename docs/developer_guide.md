# Developer Guide

## Project Structure

- `kaseki/`: Contains the main source code.
- `tests/`: Unit and integration tests.
- `docs/`: All about docs, contains the .md files.
- `docs/ssh_api_reference/`: Contains the docs for the ssh bruteforcing modules
- `docs/utils_api_reference/`: Contains the docs for utilities modules like producer.py and consumer.py
